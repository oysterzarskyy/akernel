Build steps/Other host OS

OTHER LINUX AND UNIX-LIKE HOSTS

Build from another OS

Use a Linux guest when your host does not provide the expected GCC and ELF linker setup.

!

The host operating system is not the kernel target. akernel's Makefile expects a GNU-compatible shell, GNU Make, GCC, NASM, and ELF-capable linkers. Native output formats such as Mach-O or PE are not substitutes for ELF.

RECOMMENDED FALLBACK

Create an isolated Ubuntu VM

  1. 01

    Use a desktop hypervisor available for your host OS and create an Ubuntu 24.04 LTS x86-64 guest with a virtual disk, 2 CPU cores, and at least 2 GB RAM.

  2. 02

    Install Ubuntu only on the virtual disk. Never attach a physical host disk; take a snapshot before testing.

  3. 03

    Follow the Ubuntu build guide inside the guest to install dependencies, clone the source, and build.

NATIVE BUILDS

Toolchain requirements

If you already have a supported native toolchain, install GNU Make, GCC with -m32 and -m64 support, GNU binutils with i386 and x86-64 ELF linker modes, NASM, Git, curl, tar, sha256sum, and xorriso.

From a checkout of the repository, run make for legacy ELF targets or make iso for the Limine x86-64 test image. If your host lacks the required tools, use the Ubuntu VM workflow instead of substituting a native executable format.

BETA TESTING

Use the ISO in a disposable VM

The ISO target includes Limine for x86-64 BIOS and UEFI boot, but is only a kernel scaffold and not a package installer or complete OS. Boot it as virtual CD media in a disposable VM. Do not write it to a physical disk or replace your host operating system.
