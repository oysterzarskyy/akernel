Build steps/Windows with WSL 2

WINDOWS · WSL 2 · UBUNTU

Build on Windows

Use Ubuntu in WSL 2 to run the Linux ELF compiler and build tools.

!

Build the ISO inside Ubuntu on WSL 2, then attach it to a disposable VM for testing. It is not a Windows installer; do not write it to a physical disk.

01 — ENABLE WSL 2

Install Ubuntu from PowerShell

Open Windows Terminal or PowerShell as Administrator and run:

POWERSHELL · ADMINISTRATORWindows 10/11
wsl --install -d Ubuntu-24.04

Restart if Windows requests it, open Ubuntu from the Start menu, and complete the first-run Linux username setup.

02 — BUILD IN UBUNTU

Install tools and compile

Run the following inside the Ubuntu terminal, not PowerShell. Keep the checkout under the Linux home directory (for example, ~/akernel) for better filesystem performance:

UBUNTU · WSL 2build both architectures
sudo apt update
sudo apt install -y build-essential gcc-multilib binutils nasm git file curl xorriso zip unzip
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel
make
make CC=gcc iso-zip

The default branch builds the 1.2.1.067 AASH nightly prerelease. The ISO is built with GCC inside Ubuntu on WSL 2; stable 1.2.1 remains available separately.

03 — VERIFY

Inspect the generated ELF files

UBUNTU · WSL 2build directory
file build/x86/kernel.elf build/x86_64/kernel.elf
readelf -h build/x86/kernel.elf
readelf -h build/x86_64/kernel.elf

The ISO is for booting in a disposable VM. WSL itself is not the target machine; do not attach a physical disk or try to replace the Windows or WSL bootloader.
