Build steps/Fedora

LINUX · DNF

Build on Fedora

Install the compiler, ISO tools, and Git to compile both ELF targets and optionally build a Limine ISO.

!

The opt-in ISO target supports x86-64 VM testing. It is not an installer; use a disposable VM and never write outputs to a physical disk.

01 — INSTALL TOOLS

Install dependencies

TERMINALFedora
sudo dnf install -y gcc make binutils nasm git file curl xorriso zip unzip

The build is freestanding and does not link against the guest's C library. GCC must accept the -m32 and -m64 options; GNU binutils must provide the i386 and x86-64 ELF link modes.

02 — GET THE SOURCE

Clone the repository

TERMINALclone default branch
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel

Version 1.2.1 "Slim Jims" is built from the repository's default branch; the source snapshot does not use a release tag.

03 — COMPILE AND VERIFY

Build and inspect outputs

TERMINALrepository root
make
file build/x86/kernel.elf build/x86_64/kernel.elf
readelf -h build/x86/kernel.elf
readelf -h build/x86_64/kernel.elf

To create the pinned Limine v12.9.4 BIOS/UEFI ISO and ZIP with GCC, run make CC=gcc iso-zip. To test it in QEMU, also install qemu-system-x86 and run make run-qemu. The legacy ELF outputs are not bootable by themselves.
