Build steps/Ubuntu and Debian

LINUX · APT

Build on Ubuntu or Debian

Install GNU build tools, compile both ELF targets, and optionally create the Limine x86-64 test ISO.

!

The optional ISO target boots the x86-64 kernel through Limine. Test it only in a disposable VM; it is not an installer. Never write the ISO to a physical disk.

01 — INSTALL TOOLS

Install dependencies

Open a terminal and install the build tools, ISO utilities, and file inspection tools:

TERMINALUbuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib binutils nasm git file curl xorriso zip unzip qemu-system-x86

02 — GET THE SOURCE

Clone the repository

TERMINALclone default branch
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel

The nightly is an untagged source snapshot. This builds the repository's default branch.

COMPILERGCC
gcc --version
make CC=gcc

03 — COMPILE

Build both architectures

From the repository root, build the 32-bit x86 and 64-bit x86-64 targets:

TERMINALrepository root
make

To build a single target, run make check-x86 or make check-x86_64.

04 — BUILD AND TEST THE ISO

Create a Limine boot image

The opt-in target downloads the pinned Limine v12.9.4 binary package, verifies its SHA-256, and creates an x86-64 BIOS/UEFI ISO in build/:

TERMINALrepository root
make CC=gcc iso-zip
make run-qemu

Alternatively, attach build/akernel-v1.2.0nr-x86_64.iso as virtual CD media in a disposable VM. Do not attach a physical disk.

The compressed ISO and checksum are build/akernel-v1.2.0nr-x86_64.zip and build/akernel-v1.2.0nr-x86_64.zip.sha256.

05 — VERIFY OUTPUTS

Inspect the ELF and ISO files

TERMINALoutput checks
file build/x86/kernel.elf build/x86_64/kernel.elf
readelf -h build/x86/kernel.elf
readelf -h build/x86_64/kernel.elf
file build/akernel-v1.2.0nr-x86_64.iso

The legacy ELF outputs are not bootable on their own. Only the x86-64 Limine ISO target is intended for VM boot testing.
