Build steps/Ubuntu and Debian

LINUX · APT

Build on Ubuntu or Debian

Install GNU build tools, clone the source, and produce both kernel ELF targets.

!

This creates kernel ELF files only. It does not create an ISO or a bootable operating system. For beta testing, run these commands in a disposable Ubuntu VM; never write outputs to a disk.

01 — INSTALL TOOLS

Install dependencies

Open a terminal and install GNU Make, GCC multilib support, binutils, NASM, Git, and file inspection tools:

TERMINALUbuntu / Debian
sudo apt update
sudo apt install -y build-essential gcc-multilib binutils nasm git file

02 — GET THE SOURCE

Clone the repository

TERMINALclone default branch
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel

There is currently no published version tag. This builds the repository's default branch. After v1.1.109403 is published, you can select that exact source with:

OPTIONALafter the tag is published
git fetch --tags
git checkout v1.1.109403

03 — COMPILE

Build both architectures

From the repository root, build the 32-bit x86 and 64-bit x86-64 targets:

TERMINALrepository root
make

To build a single target, run make check-x86 or make check-x86_64.

04 — VERIFY OUTPUTS

Inspect the ELF files

TERMINALoutput checks
file build/x86/kernel.elf build/x86_64/kernel.elf
readelf -h build/x86/kernel.elf
readelf -h build/x86_64/kernel.elf

The build outputs are build/x86/kernel.elf and build/x86_64/kernel.elf. ELF format alone does not make them bootable. Do not use qemu -kernel or write them to a disk; this beta has no bootloader or boot protocol.
