Build steps/Arch Linux

LINUX · PACMAN

Build on Arch Linux

Install the build and ISO tools, then optionally create a Limine x86-64 test image.

!

The optional Limine ISO is intended for VM boot testing only, not installation. Use a disposable VM and never write output to a physical disk.

01 — INSTALL TOOLS

Update the system and install dependencies

Use a complete system update, then install the compiler toolchain, GNU Make, binutils, NASM, and Git:

TERMINALArch Linux
sudo pacman -Syu --needed base-devel gcc binutils nasm git file curl xorriso

02 — GET THE SOURCE

Clone the repository

TERMINALclone default branch
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel

After release tag v1.1.109403 is published, you can check out that exact version with git fetch --tags and git checkout v1.1.109403.

03 — COMPILE AND VERIFY

Build and inspect outputs

TERMINALrepository root
make
file build/x86/kernel.elf build/x86_64/kernel.elf
readelf -h build/x86/kernel.elf
readelf -h build/x86_64/kernel.elf

To build the pinned Limine v12.9.4 BIOS/UEFI ISO, run make iso. For QEMU testing, install qemu-system-x86 and run make run-qemu. The standalone ELF targets remain non-bootable.
