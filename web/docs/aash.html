NIGHTLY 1.2.1.067 · EXPERIMENTAL LANGUAGE

AASH

A small, freestanding, shell-like command language interpreted by the akernel boot code.

!

AASH is an early preview, not a general-purpose shell. It currently executes the boot script embedded in the kernel. There is no interactive prompt, keyboard input, filesystem, or external script loader.

01 — COMMANDS

One command per line

AASH uses a simple command followed by plain-text arguments. It does not yet parse quotes, variables, pipes, conditionals, or command substitution.

AASHboot script syntax
# comments start at the beginning of a line
color cyan
echo AASH nightly setup preview
version
setup
help
color green
echo TEXTWrite text and a newline to the framebuffer console.
color NAMESet the foreground to red, green, yellow, blue, magenta, cyan, or white.
setupRun the non-destructive first-boot preflight display.
versionPrint the kernel and AASH versions.
helpPrint the built-in command list and current language limits.

The current boot script is defined in pkg/akernel/setup/setup.c and interpreted by pkg/akernel/aash/aash.c. Run make test-aash for parser and command-dispatch tests.

02 — SETUP PREVIEW

A safe preflight, not an installer

The setup command checks that the Limine boot path and framebuffer console are usable, then displays the missing capabilities that block a real OS installer. It does not write to storage or make persistent changes.

  • Framebuffer output is available for status messages.
  • Keyboard input, storage drivers, and filesystem support are not implemented.
  • No disk is partitioned, formatted, or modified.
  • Booting the image is only supported as virtual optical media in a disposable VM.

Choc-OS installation is not available. The proposed first layout is UEFI/GPT with a FAT32 EFI System Partition and no separate root filesystem, but it is not implemented or validated. Do not partition or format a host disk, and do not attach a physical or non-disposable disk to the VM.

03 — NIGHTLY LIMITS

Language and release status

AASH is inspired by shell languages such as Bash, Zsh, and Fish, but it is its own language and does not run their scripts. The interpreter is written in freestanding C and runs a compiled-in script; it is not a userspace program.

Version 1.2.1.067 is an experimental prerelease. It must not be treated as the stable 1.2.1 release or as a complete operating system. Download it from the nightly GitHub prerelease and follow the VM safety guidance.
