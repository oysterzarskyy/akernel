02 — BUILD FROM SOURCE

Create the beta ISO locally

On a Linux environment with the required compiler, NASM, GNU Make, curl, and xorriso installed, clone the project and build the ISO:

TERMINALLinux or WSL 2
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel
make iso

The generated file is build/akernel-1.1.109403-x86_64.iso. The Makefile verifies the pinned Limine binary archive checksum before packaging it. See the host-specific build guides for prerequisites.

03 — TEST SAFELY

Use a disposable virtual machine

  • This beta is a kernel scaffold, not an operating system or installer.
  • Boot the ISO only in a disposable virtual machine with no physical disk passthrough.
  • Do not write the image to a USB drive or install it over an existing system.
  • Verify any future published checksum before using an ISO.
