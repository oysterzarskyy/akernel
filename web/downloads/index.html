02 — BUILD FROM SOURCE

Create the version 1.2.1 ISO locally

On a Linux environment with GCC, NASM, GNU Make, curl, xorriso, and zip installed, clone the project and package the ISO:

TERMINALLinux or WSL 2
git clone https://github.com/oysterzarskyy/akernel.git
cd akernel
make CC=gcc iso-zip

For MSYS2 UCRT64, install the packaging tools with pacman -S --needed base-devel curl git xorriso zip unzip and put an x86_64-elf GCC cross-toolchain on PATH. The native UCRT64 GCC targets Windows PE, not the ELF kernel. Build with:

MSYS2 UCRT64Cross-compiler
make CC_X86_64=x86_64-elf-gcc LD_X86_64=x86_64-elf-ld iso-zip

The generated files are build/akernel-v1.2.1-x86_64.iso, build/akernel-v1.2.1-x86_64.zip, and build/akernel-v1.2.1-x86_64.zip.sha256. The Makefile verifies the pinned Limine binary archive checksum before packaging it. See the host-specific build guides for prerequisites.

03 — TEST SAFELY

Use a disposable virtual machine

  • This version is a kernel scaffold, not an operating system or installer.
  • Boot the ISO only in a disposable virtual machine with no physical disk passthrough.
  • Do not write the image to a USB drive or install it over an existing system.
  • Verify any future published checksum before using an ISO.
